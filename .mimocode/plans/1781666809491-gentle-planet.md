## Phase 0: P0 正确性Bug修复 (3-4小时)

### 0.1 scoring.py 重复import
- **文件**: `brain_alpha_ops/research/scoring.py:789-790`
- **问题**: 两行import `_ratio`和`normalize_brain_ratio`——第789行相对导入，第789行绝对导入，后者覆盖前者
- **修复**: 删除第789行，保留第789行(绝对导入+S-13注释)
- **验证**: `ruff check brain_alpha_ops/research/scoring.py`

### 0.2 convergence.py bootstrap非确定性
- **文件**: `brain_alpha_ops/research/convergence.py:397`
- **问题**: `random.choice(values)`使用未播种的全局RNG，结果不可复现
- **修复**: 在`ConvergenceTracker.__init__`和`_bootstrap_ci`添加可选`rng: random.Random | None = None`参数，默认`random.Random(42)`
- **验证**: 两次运行相同数据→结果必须一致

### 0.3 attribution.py KeyError风险
- **文件**: `brain_alpha_ops/scoring/attribution.py:194`
- **问题**: `scorecard["total_score"]`直接访问，而第192行用`.get()`——若key缺失则崩溃
- **修复**: 改为`contribution=scorecard.get("total_score", 0)`
- **验证**: `ruff check brain_alpha_ops/scoring/attribution.py`

### 0.4 alpha_checks.py 函数内import
- **文件**: `brain_alpha_ops/research/alpha_checks.py:758`
- **问题**: `import re`在函数体内
- **修复**: 移至文件顶部import区域
- **验证**: `ruff check brain_alpha_ops/research/alpha_checks.py`

### 0.5 anti_overfit.py 死代码
- **文件**: `brain_alpha_ops/research/anti_overfit.py:104-110`
- **问题**: `_synthetic_ic_series`定义但从未被调用（P0-1修复后的遗留）
- **修复**: 删除函数及不再使用的`hashlib`/`random` import
- **验证**: `ruff check brain_alpha_ops/research/anti_overfit.py` + grep确认无调用者

### 0.6 rolling_validation.py 合成fallback
- **文件**: `brain_alpha_ops/research/rolling_validation.py:84-87`
- **问题**: 无真实IC序列时用`fitness×[0.85,0.95,1.0,0.9]`模拟，掩盖真实退化
- **修复**: 改为`return []`（与anti_overfit的insufficient_data模式一致）
- **验证**: `pytest tests/test_rolling*.py -x -q`

**Phase 0验证**: `pytest tests/ -x -q` 全部通过
