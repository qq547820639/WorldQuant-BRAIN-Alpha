# BRAIN Alpha Ops 深挖优化计划

## 概述
本计划针对 BRAIN Alpha Ops 前端项目进行深度优化，涵盖性能优化、测试覆盖增强、代码质量提升三个维度。

## 当前状态分析

### 1. 已完成的工作（对外产品升级）
- ✅ 错误边界、全局通知、暗色模式
- ✅ 确认对话框、键盘快捷键、导出功能
- ✅ 加载状态、空状态统一优化
- ✅ 可访问性优化、引导与帮助系统
- ✅ 构建产物优化（gzip 75KB < 300KB 目标）

### 2. 发现的问题

#### 性能优化
| 问题 | 位置 | 严重程度 |
|------|------|---------|
| 大量组件未使用 React.memo | CandidateRow, Tooltip, JobMonitor 系列组件 | 高 |
| 缺少防抖处理 | ConfigPanel, CandidateTable 搜索过滤 | 中 |
| 缺少节流处理 | 滚动事件、resize 事件 | 中 |
| 大型组件未拆分 | CandidateTable.tsx (700+ 行), ScoringPanel.tsx | 高 |

#### 测试覆盖
| 组件 | 当前覆盖状态 |
|------|------------|
| Toast / ToastContainer | 无测试 |
| ConfirmDialog | 无测试 |
| ErrorBoundary | 无测试 |
| KeyboardShortcuts | 无测试 |
| useTheme / useKeyboardShortcuts | 无测试 |
| CandidateTable 核心逻辑 | 无测试 |

#### 代码质量
| 问题 | 描述 |
|------|------|
| 大型组件 | CandidateTable.tsx (~700行)、ScoringPanel.tsx (~500行) |
| 重复代码 | 多个组件有相似的错误处理逻辑 |
| 缺少类型导出 | 某些 utility 类型未从 index.ts 导出 |

## 优化方案

### Phase 1: 性能优化

#### 1.1 React.memo 缺失修复
**目标文件**：
- `src/components/CandidateRow.tsx` - 添加 memo 包装
- `src/components/Tooltip.tsx` - 添加 memo 包装
- `src/components/JobMonitor/JobProgressBar.tsx` - 添加 memo 包装
- `src/components/JobMonitor/JobActions.tsx` - 添加 memo 包装
- `src/components/JobMonitor/JobStatusCard.tsx` - 添加 memo 包装
- `src/components/LoadingProgress.tsx` - 添加 memo 包装

**改动内容**：
- 将函数组件包装在 `React.memo()` 中
- 确保 props 比较正确，避免误判

#### 1.2 防抖处理
**目标文件**：
- `src/components/CandidateTableToolbar.tsx` - 搜索输入防抖
- `src/components/ConfigPanel.tsx` - 配置输入防抖
- `src/components/CandidateTableSubComponents.tsx` - 如果有滚动事件

**改动内容**：
- 引入或创建 useDebounce hook
- 对高频输入事件添加 300ms 防抖

#### 1.3 useCallback/useMemo 优化
**目标文件**：
- 大型组件中频繁创建的回调函数

**改动内容**：
- 检查依赖数组是否正确
- 移除不必要的 useMemo/useCallback
