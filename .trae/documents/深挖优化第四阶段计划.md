## Proposed Changes

### Task 1: Dashboard.tsx 拆分

**目标**: 将 500 行组件拆分为多个文件，单个文件 ≤ 400 行

**文件结构**:
```
components/Dashboard/
├── index.ts                    # 重新导出 Dashboard
├── Dashboard.tsx               # 主组件（保留核心逻辑）
├── DashboardHeader.tsx         # 标题栏 + 手动同步按钮
├── DashboardKpiSection.tsx     # KPI 卡片区域
├── DashboardSnapshotSection.tsx # 快照展开区域
├── DashboardGuides.tsx         # GuidePanel + StepLabel
├── DashboardPanels.tsx         # MemoryPanel + FailurePatternsPanel
├── DashboardNotices.tsx        # SyncCloudCTA + CacheModeNotice + PhaseStatusNotice
└── utils.ts                   # computeTrendChange 工具函数
```

**改动内容**:
1. 创建 `Dashboard/` 子目录
2. 将 `Dashboard.tsx` 移动到 `Dashboard/Dashboard.tsx`
3. 提取辅助组件到独立文件：
   - `DashboardGuides.tsx`: GuidePanel + StepLabel（~90行）
   - `DashboardPanels.tsx`: MemoryPanel + FailurePatternsPanel（~60行）
   - `DashboardNotices.tsx`: SyncCloudCTA + CacheModeNotice + PhaseStatusNotice（~80行）
4. 创建 `Dashboard/index.ts` 统一导出
5. 更新所有 import 路径
6. 验证 TypeScript 类型检查通过
