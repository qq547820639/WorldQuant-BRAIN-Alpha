### 核对结果
- `brain_alpha_ops/domains/` 不是"5 个空 stub" — 是 v4.0 域 API 入口点
- 内容: 5 个 re-export 模块 (scoring/generation/backtest/simulation/strategy)
  - scoring.py: build_scorecard, AlphaCheckRegistry, AntiOverfitService, ConvergenceTracker
  - generation.py: CandidateGenerator, HypothesisLibrary
  - backtest.py: LocalBacktestEngine, BacktestSlotManager
  - simulation.py: OfficialValidationService
  - strategy.py: StrategyLifecycleManager, StrategyPluginRegistry, StrategySwitch, DatasetSelector
- 现状 (2026-06-13 18:43): **没有任何代码 import 它** (grep 验证)
- 但是: 它是 v4.0 文档化的 API, 删除会破坏 v4.0 契约

### 错误根源
- Phase 1/2 时我看到 "5 个 2-5 行 re-export" 就判为"空 stub"删除
- 没意识到它们是 v4.0 公共 API 的入口点
- 没核对 docs/examples 是否引用 (实际没引用, 但契约本身有价值)
