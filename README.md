# BRAIN Alpha Ops

> **你的量化研究小助手 — 帮你省时省力地「找 alpha」，但敲下提交键的永远是你自己。**

BRAIN Alpha Ops 是一款跑在你**自己电脑**上的工具，专门帮助使用 WorldQuant BRAIN 平台的用户，自动完成找策略、做测试、打分、挑优这些繁琐的活儿，最后把一份清清楚楚的候选清单交给你，由你来决定下一步。

---

## 📌 它解决了什么问题？

如果你在 WorldQuant BRAIN 平台上找过策略（也就是「alpha」），你一定懂这种感受：

- 想在成千上万个数据字段里找到灵感，头大；
- 手动写策略、跑测试、反复调整，又慢又累；
- 一堆策略跑出来，不知道哪个靠谱、为什么靠谱。

**BRAIN Alpha Ops 就是来解决这些烦恼的。** 它像一个不知疲倦的助理，7×24 小时帮你干活，而你只需要做最重要的判断。

> 💡 **一句话记住它：** 自动帮你「找」和「筛」，但绝不替你「提交」。

## ✨ 它能为你做什么？

| 工具自动帮你做的事 | 你需要做什么 |
|------------------|------------|
| 从 11 类投资想法里自动生成候选策略 | 选一个你感兴趣的研究方向 |
| 在本地快速筛选，过滤掉明显不靠谱的 | 什么都不用做 |
| 调用官方平台做真实回测、打分 | 什么都不用做 |
| 自动尝试优化低分策略 | 什么都不用做 |

工具内置了 **11 种经典投资思路**，比如「价值反转」（跌多了会反弹）、「低波动」（稳一些的股票可能有超额收益）、「盈利上修」（分析师上调预期往往会涨）等，你可以随时打开或关闭，也可以自己扩展。

它的拿手好戏是：把每个策略为什么得分高、为什么被淘汰，都讲得明明白白，让你不是对着一个「黑盒」看结果。

## 🚀 快速上手：三步开始使用

### 第一步：准备

| 你需要 | 说明 |
|-------|------|
| 一台电脑（Mac / Windows / Linux） | 需要 Python 3.12 及以上版本 |
| 一个 WorldQuant BRAIN 账号 | 在 [brain.worldquant.com](https://brain.worldquant.com) 注册即可 |
| 一个现代浏览器 | Chrome / Edge / Safari / Firefox 都行 |
| 约 10GB 硬盘空间 | 首次启动会下载平台数据到本地 |

### 第二步：安装并启动

```bash
# 1. 下载代码
git clone https://github.com/<your-github-username>/WorldQuant-BRAIN-Alpha.git
cd WorldQuant-BRAIN-Alpha

# 2. 安装依赖（只需一次）
python3 -m venv .venv
source .venv/bin/activate        # Windows 用: .venv\Scripts\activate
python3 -m pip install -e .

# 3. 启动！
python3 launch_web.py
```

启动后，浏览器会自动打开一个本地页面（地址是 `http://127.0.0.1:8765`），这就是你的工作台。

### 第三步：连接你的账号

1. 在左侧菜单点击「系统配置」；
2. 填上你的 BRAIN **用户名 + 密码**（或 Token）；
3. 点击「测试连接」；
4. 等待首次同步完成（约 30 秒到 2 分钟）。

> 🔒 密码只在内存里，不会写进硬盘、日志或截图。重启后需要重新输入，这是故意的，为了你的安全。

## 🧭 工作台长什么样？

整个工作台围绕一次完整的「找策略」流程来组织，一共分四个阶段：

1. **连接与准备** — 登录账号，加载你的个人资料和平台数据；
2. **生成候选** — 点击「开始运行」，工具自动按你选的主题生成一批候选策略；
3. **评估与验证** — 通过筛选的候选会送入官方平台做真实回测，并自动打分、优化；
4. **提交就绪** — 高分候选进入清单，你在这一步**最终拍板**。

界面上有多个功能面板，分别负责查看运行状态、管理候选、查看打分明细、做提交前的最终确认等。每个面板都配有清晰的说明，跟着操作即可。

## ❓ 常见问题

**问：它会自动帮我提交吗？**
答：**绝对不会。** 这是工具的设计底线——最后的提交动作永远需要你亲自确认。代码层面也做了硬性保护，没有任何策略会在没人确认的情况下被提交。

**问：我的密码安全吗？**
答：安全。凭证只在内存中管理，绝不写入文件、日志或截图，输出内容也会自动脱敏。

**问：会消耗我的 BRAIN 额度吗？**
答：会。每次真实回测都会消耗一次平台调用额度。工具内置了自动限速，避免过度消耗。

**问：能保证赚到钱吗？**
答：不能，任何工具都不能保证。BRAIN Alpha Ops 是帮你**更高效地研究**，而不是替你承诺收益。请把它当作研究助手，结合自己的判断使用。

**问：支持 Windows 吗？**
答：支持。Python 是跨平台的，Windows 上只是个别命令写法略有不同，文中有标注。

**问：是免费的吗？**
答：免费开源（MIT 协议）。使用 BRAIN 平台本身需遵守 WorldQuant 的服务条款。

## 📎 附录：给进阶用户的说明

以下内容面向开发者、贡献者以及想深入了解内部机制的用户，普通用户可跳过。

### 技术概览

- **定位**：本地运行的 alpha 研究工作台，非云端 SaaS，数据由你掌控。
- **评分体系**：按「先验 30% + 实证 45% + 清单 25%」三层，共 32 项检查给每个候选打分，并设有 9 个硬性门槛（如夏普比率、换手率、相关性等），不满足门槛的候选会被拦截。
- **可解释性**：每个分数都有归因树，说明每个维度的得分与权重，失败项会给出具体改进建议。
- **安全模型**：凭证仅存内存、默认仅监听本机、日志自动脱敏、真实提交需人工双重确认（HIL 人机协同闸门）、内置速率限制与密钥泄露扫描。

### 开发与贡献

- **代码结构**：后端在 `brain_alpha_ops/`，前端在 `brain_alpha_ops/web/react_app/`，质量门禁脚本在 `scripts/`。
- **本地开发**：`python -m pip install -e ".[test,dev]"` 安装依赖；`python -m pytest tests/` 运行后端测试。
- **质量门禁**：提交前请运行 `python scripts/quality_gate` 与 `python scripts/final_release_gate.py`。
- **贡献红线**：请保持安全原则不变——默认禁止自动提交、真实提交需人工确认、凭证永不落盘/日志/截图。

### Docker 部署（可选）

```bash
docker build -t brain-alpha-ops .
docker run -p 8765:8765 brain-alpha-ops
# 或使用 docker-compose
docker compose up -d
```
