## 一、设计理念

### 美学方向：Terminal Precision（终端精度）

这不是对 Bloomberg Terminal 的临摹，而是一种设计哲学：

- **Chrome 退后，数据前进** — 界面框架越少越好，数据本身即是界面
- **色彩是信号，不是装饰** — 每个颜色都有语义含义，不为美观而着色
- **单色空间 + 精准点缀** — 95% 的中性灰阶，5% 的琥珀色信号
- **工业感，不是科技感** — 避免霓虹、渐变、发光等 AI 惯用套路

### 核心区别于常见 AI 设计

| AI Slop（我们不做） | Terminal Precision（我们做） |
|---|---|
| 紫色→蓝色渐变 | 温暖的暗灰色调，单一琥珀焦点色 |
| 毛玻璃卡片 + 圆角阴影 | 平坦表面，0.5px 细线分隔 |
| 巨型 KPI 数字 + 大图标 | 紧凑的等宽数字，密集表格 |
| 紫/青霓虹点缀 | 收敛的语义色，仅用于状态标示 |
| hero section + 居中布局 | 侧边栏 + 全宽数据视口 |

## 二、颜色体系

### 设计原则
- 使用 OKLCH 色彩空间（感知均匀，暗色模式下更自然）
- 中性色调带有微暖色调（chroma 0.007 @ hue 45），避免纯粹的灰色
- 不使用纯黑 #000（自然界不存在纯黑）
- 暗色模式深度通过表面色差表达，不依赖阴影

### 主色调板

| Token | 用途 | 色值 |
|---|---|---|
| `--surface-root` | 页面底色 | `oklch(0.085 0.006 45)` |
| `--surface-1` | 卡片/面板 | `oklch(0.100 0.007 45)` |
| `--surface-2` | 顶部栏/表头 | `oklch(0.115 0.007 45)` |
| `--surface-3` | 悬浮/弹出层 | `oklch(0.135 0.008 45)` |

### 文本色板

| Token | 用途 | 对比度 |
|---|---|---|
| `--text-primary` | 正文/主要数据 | 13.5:1 (AAA) |
| `--text-secondary` | 次要信息/表格数据 | 7.8:1 (AAA) |
| `--text-tertiary` | 标签/提示/不可操作 | 4.8:1 (AA) |
| `--text-disabled` | 禁用态 | 3.2:1 |

### 焦点色：琥珀

唯一的功能色用于交互焦点和重要数据高亮：

| 场景 | 色值 |
|---|---|
| CTA 按钮 | `oklch(0.65 0.14 80)` |
| 悬停态 | `oklch(0.72 0.12 83)` |
| 已排序表头 | `oklch(0.65 0.14 80)` |
| 选中行/侧边栏激活 | `oklch(0.65 0.07 80 / 0.12)` |

**原则**：琥珀色占界面总面积的 < 5%（60-30-10 规则的 10%）

### 语义色

| 语义 | 背景 | 文字 | 用途 |
|---|---|---|---|
| 成功/达标 | `oklch(0.52 0.06 155 / 0.15)` | `oklch(0.62 0.10 160)` | 通过状态、正向指标 |
| 错误/阻断 | `oklch(0.48 0.06 22 / 0.15)` | `oklch(0.58 0.12 25)` | 失败状态、负向指标 |
| 警告/待审 | `oklch(0.65 0.06 85 / 0.15)` | `oklch(0.75 0.10 88)` | 警告、待处理 |
| 信息/中性 | `oklch(0.58 0.06 245 / 0.12)` | `oklch(0.68 0.10 248)` | 信息提示、链接 |

## 三、排版系统

### 字体选择

| 角色 | 字体 | 理由 |
|---|---|---|
| 显示/UI | DM Sans | 几何感、现代、可读性高 |
| 等宽/数据 | JetBrains Mono | 清晰区分 `0O` `1lI`，适合表格 |
| 回退 | system-ui, -apple-system | 零加载时间的系统字体 |

> 不使用 Inter/Roboto — 它们是"AI 设计的默认字体"

### 字号层级（Major Third 1.25 比例）

| 用途 | 大小 | 字重 |
|---|---|---|
| 微型标签 / 坐标轴 | 11px | 600 |
| 表格单元格 / 辅助数据 | 13px | 400 |
| 正文 / 主要数据 | 15px | 400 |
| 强调数据 / 导航 | 17px | 500 |
| 区块标题 | 20px | 500 |
| 面板标题 | 24px | 500 |
| KPI 大数字 | 30px | 500 (等宽) |
| 特大型指标 | 38px | 500 (等宽) |

### 排版规则

1. **等宽数字** — 所有数值、指标、表格数据使用 `font-variant-numeric: tabular-nums`
2. **大写标签** — 所有标签/表头使用 uppercase + letter-spacing 0.05em
3. **固定字号** — 不使用 fluid typography；数据界面需要精确的空间控制
4. **暗色模式下增加 0.05 line-height** — 补偿暗色文字感知更轻的问题

## 四、空间系统

### 4px 基准网格

所有间距从 4px 开始，使用倍数递增：
`4px → 8px → 12px → 16px → 20px → 24px → 32px → 40px → 48px → 64px`

### 密度原则

| 区域类型 | 内边距 | 间距 |
|---|---|---|
| 页面级别 | 16px | — |
| 面板/卡片 | 12px-16px | 面板间 12px |
| 表格单元格 | 8px × 12px | — |
| 紧凑面板 | 8px-12px | 面板间 8px |
| 按钮 | 8px × 16px | 按钮间 8px |
| 侧边栏导航项 | 8px × 12px | 项目间 1px |

### 倒角统一
- 卡片/面板：6px
- 按钮/输入框：4px
- 徽章/标签：2px
- 表格/分隔线：0px

## 五、布局架构

### 应用外壳（App Shell）

```
┌──────────────────────────────────────────────────────┐
│  Top Bar (44px)              │ 环境 · 账户 · 设置    │
├────────────┬─────────────────────────────────────────┤
│            │                                         │
│  Sidebar   │         主内容区域                       │
│  220px     │                                         │
│            │   KPI 卡片行                            │
│  ▸ 运行总览 │                                         │
│    候选管理 │   数据表格 / 图表 / 详情                 │
│    回测监控 │                                         │
│    科学评分 │                                         │
│    质量门禁 │                                         │
│    阻断复核 │                                         │
│    ─────── │                                         │
│    续跑记录 │                                         │
│    云端快照 │                                         │
│    系统配置 │                                         │
│            │                                         │
├────────────┴─────────────────────────────────────────┤
│  Status Bar (28px)           │ v2.0 · 本地非提交页面  │
└──────────────────────────────────────────────────────┘
```

### 响应式策略

| 断点 | 布局 |
|---|---|
| ≥ 1024px | 完整布局：侧边栏 220px + 主区域 |
| < 1024px | 侧边栏折叠为抽屉，顶部栏增加汉堡菜单 |
| < 640px | 全宽单列，表格横向滚动 |

### 导航模式

从旧版的"卡片网格导航"改为"持久化左侧边栏导航"：

**理由**：
1. 10 个模块在卡片网格中导航需要返回 → 选择 → 返回，效率低
2. 侧边栏始终可见，一键切换，无需返回首页
3. 与金融终端（Bloomberg/Eikon）的导航模式一致
4. 支持显示模块级徽章（如 candidates 数量、active slots 数）

## 六、组件库

### 6.1 按钮

| 变体 | 使用场景 | 每页限制 |
|---|---|---|
| Primary（琥珀色填充） | 主要 CTA，每视图最多 1 个 | 1 |
| Secondary（表面 + 边框） | 常规操作 | 不限 |
| Ghost（透明） | 辅助/导航操作 | 不限 |
| Danger（红色透明） | 不可逆操作 | 最少 |

按钮最小高度 32px，触摸目标 ≥ 44px（通过内边距保证）。

### 6.2 数据表格

金融终端的核心组件。要求：

- 等宽字体用于数值列
- 粘性表头（sticky header）
- 可排序列（点击表头排序，已排序列显示琥珀色）
- 行悬停高亮
- 行选中高亮（琥珀色透明背景）
- 紧凑模式用于高密度场景（8px 单元格内边距）
- 数值右对齐，文本左对齐

### 6.3 KPI 卡片

两种密度：
- **标准**：垂直布局，标签在上、数值在下，用于 Dashboard
- **行内**：水平布局，标签在左、数值在右，用于面板标题栏

### 6.4 徽章

统一使用背景色 + 文字色的双色方案，无边框。六种语义变体：neutral、positive、negative、warning、info、accent。

### 6.5 进度反馈

- 进度条：3px 高度，琥珀色填充
- 不确定进度：左→右循环动画
- 旋转指示器：16px，用于行内加载

### 6.6 状态点

6px 圆点，用于表格、列表中的状态标示：
- 绿色脉冲 = 活跃
- 灰色 = 空闲
- 红色 = 错误
- 黄色 = 警告
- 蓝色脉冲 = 等待中

## 七、数据可视化规范

### 图表配色

| 数据含义 | 颜色 |
|---|---|
| 正值/收益 | `oklch(0.52 0.10 155)` 绿 |
| 负值/亏损 | `oklch(0.48 0.12 22)` 红 |
| 中性/参考线 | `oklch(0.45 0.005 45)` 灰 |
| 高亮/选中 | `oklch(0.65 0.14 80)` 琥珀 |
| 辅助系列 | `oklch(0.50 0.08 188)` 青 |

### 图表类型与用途

| 图表 | 适用数据 |
|---|---|
| 迷你折线图（sparkline） | 表格内的趋势指标（Sharpe/Fitness 时间序列） |
| 水平条形图 | 归因分解（各因子贡献度） |
| 散点图 | 候选分布（Fitness vs Sharpe） |
| 热力表格 | 质量诊断矩阵（候选 × 检查项） |
| 进度条 | 回测槽位使用率、同步进度 |

### 图表样式

- 无网格线或使用极淡网格线（`oklch(0.18 0.007 45)`）
- 坐标轴刻度使用微型等宽字体（11px）
- 无渐变填充，使用纯色
- tooltip 使用暗色表面 + 等宽数字

## 八、交互模式

### 8.1 导航

- 侧边栏始终可见，点击即时切换视图
- 当前视图高亮（琥珀色透明背景）
- 模块徽章实时更新（无需回到首页看状态）

### 8.2 数据加载

- 表格：skeleton 占位（灰色块，等宽）
- KPI：显示 "--" 占位符
- 进度操作：统一进度反馈组件
- 错误：内联错误提示 + 重试按钮

### 8.3 键盘快捷操作

| 快捷键 | 功能 |
|---|---|
| `Ctrl/Cmd + K` | 命令面板（快速导航到任意模块） |
| `Esc` | 关闭弹窗/抽屉/返回列表 |
| `↑ ↓` | 表格行导航 |
| `Enter` | 打开选中行详情 |
| `Space` | 切换选中行 |

### 8.4 渐进式披露

- 候选列表显示核心字段（ID、Sharpe、Fitness、状态）→ 点击展开完整详情
- 评分详情默认显示总分和决策区间 → 展开查看完整归因树
- 配置面板默认显示常用参数 → 展开高级选项

## 九、可访问性（WCAG AA）

- 所有正文/数据文字对比度 ≥ 4.5:1 ✓
- 所有大号文字（≥18px）对比度 ≥ 3:1 ✓
- 所有交互元素可通过键盘操作 ✓
- Focus indicator 始终可见 ✓
- 表格有正确的 `<thead>` / `<tbody>` 结构 ✓
- 颜色不是唯一的信号载体（配合图标/文字） ✓
- 支持 200% 文字缩放不破坏布局 ✓
- 暗色模式通过 CSS 变量实现，尊重 `prefers-color-scheme` ✓
